Run the supplied binary

In another terminal at the project root, run the command below and follow its prompts. The binary runs the individual cases first, then the four worker stages. Browser results apply only to requests sent by this page.

./test/tester http://127.0.0.1:8080
  • 5 workers × 15 requests · GET /
  • 20 workers × 5,000 requests · GET /
  • 128 workers × 50 requests · labeled GET /directory/nop in this binary; the worker actually requests /
  • 20 workers × 5 requests · POST /directory/youpi.bla with 100,000,000 bytes each

The checked-in tester and CGI helper are Linux x86-64 binaries. On another platform use matching builds in test/.
